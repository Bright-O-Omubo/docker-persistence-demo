# # 📦 Mongo-UI-Application

A simple Dockerized JS UI app with MongoDB + Mongo-Express using a docker compose YAML file

A 3 container project that works together:
1.  Web App  - application UI
2.  MongoDB - Database 
3.  Mongo-Express - Database UI

## DATA PERSISTENCE WITH DOCKER VOLUMES 

A perfect prototype of a  Docker running application without any local installation

## 🚀 Quick Start

## SPIN UP & DOWN IN 60 SEC
COMMAND - docker compose up -d
          
   docker compose down
